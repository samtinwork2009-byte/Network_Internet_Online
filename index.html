Network Packet Tracer

Network Packet Tracer

CCNA Network

專業級網絡模擬器，提供真實的網絡設備配置、封包傳輸模擬及故障排除環境。 支援從基礎到進階的網絡技術實作，為網絡工程師及學習者提供接近實境的練習平台。

功能模組

點擊任意模組進入對應的模擬環境，每個模組提供專屬的設備和工具

核心

核心模擬引擎

基礎網絡設計 - 拖放路由器、交換器和終端設備，建立標準企業網絡拓撲。

  • 基本拓撲：路由器 + 交換器 + PC
  • 即時模式觀察封包傳輸
  • 模擬模式逐步分析
  • 拖放操作簡單易用
💡 新手推薦從這裡開始
設備

網絡設備管理

完整設備庫 - 瀏覽和配置所有可用的 Cisco 網絡設備，了解各型號規格。

  • 路由器：1941 / 2911 / 4321
  • 交換器：2960 / 3650 / 3850
  • 無線設備：雙語 AP / WLC / Client / Mesh
  • 安全設備：防火牆 / IPS
  • 可選工具：RF Heatmap 與 AP 覆蓋/干擾掃描
📦 包含 15+ 種設備類型
協議

路由協議配置

進階路由 - 學習和配置 OSPF、EIGRP、BGP 等企業級路由協議。

  • OSPF 區域配置與鄰居建立
  • EIGRP 自治系統設定
  • BGP 邊界路由器配置
  • STP 生成樹協議
📡 適合 CCNA/CCNP 學習者
安全

安全實驗室

網絡安全 - 部署防火牆、配置 VPN 隧道、實作入侵檢測與安全策略。

  • ASA 防火牆 ACL 配置
  • Site-to-Site VPN 建立
  • IPS 入侵防禦系統
  • NAC 網絡准入控制
🔒 企業安全架構實踐
自動化

網絡自動化

DevOps 環境 - 使用 Ansible、Terraform、Python 實現網絡自動化管理。

  • Ansible 控制節點配置
  • Terraform 基礎設施即代碼
  • Docker 容器化部署
  • CI/CD 自動化流程
🤖 現代網絡運維技能
IoT

物聯網模擬

智慧環境 - 部署 IoT 感測器、攝像頭、智慧設備，模擬智慧家居場景。

  • 溫度/濕度/動作感測器
  • IP 攝像頭與監控
  • 智慧燈具與門鎖
  • IoT 閘道器連接管理
🌐 智慧家居與工業 IoT
NEW / 新功能

無線 RF 覆蓋分析 / Wireless Heatmap

RF Coverage - 即時查看 AP 訊號、頻道重疊與障礙物造成的衰減。

  • 動態 dBm 覆蓋熱圖與 AP 等訊號線
  • 2.4 / 5 GHz 頻道及同頻干擾模擬
  • 新增牆體並模擬 RF 衰減
  • 客戶端掃描、訊號強度及漫遊演示
📶 新模組，可由左側無線控制面板操作
資料中心

資料中心網絡

Spine-Leaf 架構 - 建立資料中心交換網路、負載平衡與伺服器農場。

  • Spine-Leaf 網路拓撲
  • Web 與資料庫伺服器
  • 儲存設備與負載平衡器
🗄️ 練習現代化資料中心設計
此平台為專業級網絡模擬器，採用純前端技術實現所有網絡設備、協議及數據傳輸的模擬。 所有模擬操作均為虛擬環境中的練習，並非真實的網絡接駁。真正的網絡部署需要專業設備及實體佈線。

 關於 Cisco Packet Tracer 網絡模擬器

                    
這是一個專業級網絡學習平台，提供六大模組：核心模擬（基礎拓撲設計）、設備管理（完整設備庫）、協議配置（OSPF/EIGRP/BGP）、安全實驗室（防火牆/VPN）、網絡自動化（Ansible/Terraform）及物聯網（IoT 感測器）。每個模組提供專屬的設備和工具，幫助您從入門到進階全面掌握網絡技術。

 步驟一：添加設備

                        

                            
兩種方式添加設備：

                            
    
                                
  1. 拖放方式：從左側設備庫拖曳設備到工作區指定位置
    2. 
                                
  2. 點擊方式：直接點擊設備圖標，自動添加到預設位置
    3. 
                            

                            
設備類型說明：

                            
    
                                
  • 🔀 路由器：1941 / 2911 / 4321 - 網絡層轉發
    • 
                                
  • 🔗 交換器：2960 / 3650 / 3850 - 數據鏈路層交換
    • 
                                
  • 💻 終端：PC / Laptop / Server / IP Phone
    • 
                                
  • 🛡️ 安全：ASA 防火牆 / IPS / VPN Gateway
    • 
                                
  • 📡 無線：AP / WLC 無線控制器
    • 
                            

                        

                    

                    

                        
 步驟二：連接設備

                        

                            
連線流程（三步驟）：

                            
    
                                
  1. 在「連線工具」區選擇線纜類型
    2. 
                                
  2. 點擊第一個設備（設備會亮起綠色光暈）
    3. 
                                
  3. 點擊第二個設備完成連線
    4. 
                            

                            
線纜類型選擇指南：

                            

                                
⚡ 自動連線系統自動判斷，推薦新手使用

                                
🟢 直通線不同類型設備（PC ↔ Switch）

                                
🟠 交叉線相同類型設備（Switch ↔ Switch）

                                
🟣 Console管理連接（PC ↔ Router Console）

                                
🔴 光纖高速長距離連接

                            

                        

                    

                    

                        
 步驟三：配置���備

                        

                            
基本配置流程：

                            
    
                                
  1. 點擊選中目標設備（設備邊框變藍）
    2. 
                                
  2. 在右側配置面板填寫參數：IP 位址、子網路遮罩、預設閘道
    3. 
                                
  3. 點擊「套用配置」按鈕保存設定
    4. 
                            

                            
進階配置（CLI 終端）：

                            
    
                                
  • 點擊「CLI終端」打開命令列介面
    • 
                                
  • 輸入 enable 進入特權模式
    • 
                                
  • 輸入 configure terminal 進入配置模式
    • 
                                
  • 常用命令：show ip interface brief、show running-config
    • 
                            

                        

                    

                    

                        
 步驟四：切換模式

                        

                            
四種工作模式（底部切換）：

                            
    
                                
  • ▶️ 即時模式：封包自動傳輸，觀察網絡實時運作
    • 
                                
  • ⏯️ 模擬模式：逐步分析封包，查看 OSI 各層詳情
    • 
                                
  • 📐 邏輯視圖：專注於網絡拓撲邏輯設計
    • 
                                
  • 🏢 實體視圖：模擬設備實際物理擺放位置
    • 
                            

                        

                    

                    

                        
 步驟五：測試驗證

                        

                            
可用測試工具：

                            
    
                                
  • 🔍 Ping 測試：驗證設備間連通性，顯示延遲和封包丟失率
    • 
                                
  • 🛤️ 路徑追蹤：查看封包經過的每一個跳點
    • 
                                
  • 📊 封包分析器：深入分析 OSI 七層模型的封包詳情
    • 
                                
  • 📈 效能監控：查看 CPU/記憶體/流量狀態
    • 
                                
  • 🔧 診斷工具：自動檢測網絡問題並提供建議
    •
